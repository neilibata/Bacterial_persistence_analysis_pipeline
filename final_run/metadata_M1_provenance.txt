HOW IT WAS BUILT
  Nine tools in this order, not one. Each takes --apply and copies the file
  first, so the eight .pre_* backups in this directory ARE the chain:

   1. tools/build_curated_m1.py             (base curation — see below)
   2. tools/build_subject_ids.py            -> .pre_subject_ids
   3. tools/build_verified_m1.py            -> .pre_verified
   4. tools/fix_carter_runs.py              -> .pre_carter_runs
   5. tools/clean_m1_columns.py             -> .pre_column_clean
   6. tools/fix_unsupported_flags.py        -> .pre_flag_fix
   7. tools/split_disease_bd.py             -> .pre_bd_split
   8. tools/fix_biosample_keyed_row.py      -> .pre_biosample_row
   9. tools/correct_biosample_mismatches.py -> .pre_biosample_fix

  Steps 2-9 are why the counts above differ from step 1's. Row count: 18,303
  minus the 4 Carter rows whose library has no run in the matrix (step 4).
  Health labels: MicrobiomeDB / da Silva verification (step 3) and the clearing
  of 126 unsupported flag instances (step 6) moved samples between the arms.
  Flag count: disease_BD held two unrelated diseases and became
  disease_bone_disease (54) + disease_Behcets (20) at step 7, so 68 -> 69.
  tools/audit_final_run.py pins the row count, the Unhealthy distribution and
  the absence of collisions, and is the check to run after any rebuild.
