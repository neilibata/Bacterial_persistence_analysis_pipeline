# Methods — GTDB re-alignment

Drop-in paragraph for the Methods. Generated by `tools/build_taxonomy_checklist.py`; every number is read from the GTDB-Tk run.

**Taxonomic assignment.** To place the species-level genome bins (SGBs) of both
source catalogues in a single, current taxonomic frame, every representative
genome was re-classified against the Genome Taxonomy Database (GTDB) release
r232 using GTDB-Tk v2.7.2 (`classify_wf`). All 7,565 representatives — 3,594
from the Leviatan catalogue and 3,971 from UHGG — were classified without
failure, yielding a complete lineage for every SGB in the combined 5,081-SGB
reference and replacing the mixed-provenance annotations inherited from the
source catalogues. 96% of assignments were made by average nucleotide identity
to the closest GTDB reference genome passing the species-level threshold, and
the remainder by placement in the reference tree with taxonomic novelty
determined from relative evolutionary divergence. The closest reference genome,
its ANI and alignment fraction, and the method used are retained per genome in
Table M2. 335 genomes (4.4%) fall outside the ANI radius of any named GTDB
species; because classify mode alone is not sufficient to support new taxonomic
designations, these are reported as placements within existing lineages at the
rank GTDB-Tk assigns, and no new taxa are named here. Taxonomy is used for
annotation only: no analysis in this study groups, weights, or tests samples by
taxonomic rank, so the re-alignment changes the names attached to results and
not the results themselves.
